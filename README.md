# Francesco Arezzo

My personal website, with my education, selected projects, experience and CV.

I study Mathematical and Computing Sciences for Artificial Intelligence at Bocconi University. I enjoy exploring the mathematics behind machine learning, building models from data and understanding what their predictions mean.

The site uses HTML, CSS and a small amount of JavaScript. It has a responsive layout, expandable project descriptions and a downloadable CV, with no external libraries or build step.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Homepage, styles and interactions |
| `assets/` | CV, icons and social preview image |
| `404.html` | Page shown for missing URLs |
| `robots.txt` | Search engine crawling rules |
| `sitemap.xml` | Sitemap |

## Local preview

From the repository folder, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Updates

Page content, styles and interactions are in `index.html`. The downloadable CV is `assets/Francesco_Arezzo_CV.pdf`.

The site is hosted on GitHub Pages. Changes are published through the repository's configured publishing source.
